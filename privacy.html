本頁尚未完成遊戲資料處理查核，不能據此認定遊戲完全不蒐集資料。開發者需在正式送審前依實際版本補齊下列內容，確認後更新日期與政策。

1. 適用範圍

本頁說明 Pocket Bomb iOS 遊戲、官方網站及玩家支援聯絡涉及的資料處理情況。網站的技術行為與遊戲本身分開說明。

2. 遊戲蒐集哪些資料

【待開發者確認】

請確認遊戲是否讀取、蒐集或傳送個人資料、裝置資訊、識別碼、遊玩紀錄、診斷或當機資訊。若有，需列明資料種類、取得方式、用途，以及是否與玩家身分連結；若沒有，也需完成查核後再明確說明。

3. 資料的儲存與使用

【待開發者確認】

請確認遊戲進度、零件、晶片與成長紀錄等資料儲存在裝置、雲端或其他位置，是否會離開裝置，以及備份、保存期間與刪除方式。請依實際情況說明各項資料的使用目的。

4. 第三方服務與資料分享

【待開發者確認】

請盤點遊戲實際使用的 SDK 與服務，確認是否涉及分析、當機回報、廣告、購買、平台功能或雲端儲存。若涉及第三方資料處理，請列出實際服務名稱、資料類型、用途與其隱私權政策連結。本草稿不代表已使用或未使用上述服務。

5. 官方網站

本網站由靜態 HTML、CSS 與 JavaScript 組成，沒有會員、資料庫或資料提交表單。網站程式不使用 Cookie、瀏覽器持久儲存、追蹤工具或第三方分析服務；字型與圖片不透過外部服務載入。

網站預計由 GitHub Pages 託管。託管平台處理的連線資料不等同於網站程式自行蒐集的資料；實際上線平台與適用說明需由開發者確認。可參閱 GitHub 隱私權聲明。

6. 玩家支援與聯絡資料

透過電子郵件回報時，信件可能包含你提供的電子郵件地址、裝置資訊、問題描述及附件。請只提供排查問題所需的資訊。

【待開發者確認：支援信件的使用目的、接收及存取人員、郵件服務、保存期間與刪除方式。】

7. 資料相關詢問

如想詢問資料使用、存取或刪除事宜，請透過下方聯絡方式提出。

【待開發者確認：可受理的請求範圍、身分確認方式，以及裝置端資料的管理方式。】
